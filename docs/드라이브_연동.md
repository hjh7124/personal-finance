# 구글 드라이브 연동

기록은 드라이브에, 계산은 이 리포지토리에 둔다.

개인 금융 숫자는 git에 올라가지 않고(리포지토리가 public이다), 계산 엔진은
드라이브에 들어가지 않는다. 둘을 잇는 것은 Claude와의 대화다.

## 드라이브 쪽

폴더: **퇴사후 자산관리**

| 파일 | 형식 | 대응하는 로컬 파일 |
|---|---|---|
| 지출기록 | 시트 (날짜/분류/금액/성격/메모) | `data/expenses.csv` |
| 수입기록 | 시트 (날짜/출처/금액/메모) | `data/income.csv` |
| 잔액기록 | 시트 (날짜/계좌/잔액/메모) | `data/balances.csv` |
| 기록방법 | 문서 | — |
| YYYY-MM 월간요약 | 문서 | `fin report` 출력을 다듬은 것 |

## 컬럼 대응

드라이브 시트는 사람이 폰에서 채우는 것이라 한글 헤더를 쓰고,
로컬 CSV는 엔진이 읽는 것이라 영문 헤더를 쓴다. 대응은 이렇다.

```
지출기록  날짜 → date   분류 → category  금액 → amount  성격 → kind  메모 → memo
          성격: 고정 → fixed / 변동 → variable / 비정기 → irregular

수입기록  날짜 → date   출처 → source    금액 → amount  메모 → memo

잔액기록  날짜 → date   계좌 → account   잔액 → amount  메모 → memo
          계좌 이름 → accounts.yaml 의 id 로 변환
```

## 매달 도는 흐름

1. **한 달 내내** — 폰에서 시트에 한 줄씩 추가한다.
2. **월말** — Claude에게 "이번 달 정리해줘".
3. Claude가 시트를 읽어 `data/` 의 CSV로 옮기고, `./fin` 을 돌린다.
4. 결과를 드라이브에 **YYYY-MM 월간요약** 문서로 남긴다.

로컬 CSV는 컨테이너가 사라지면 같이 사라진다. **원본은 항상 드라이브 쪽이다.**
매번 드라이브에서 가져와서 계산하고, 결과를 드라이브에 돌려놓는다.

## 계좌를 추가하거나 이름을 바꿀 때

`data/accounts.yaml` 과 드라이브의 **잔액기록** 시트를 함께 고쳐야 한다.
한쪽만 고치면 `fin validate` 가 "accounts.yaml에 없는 계좌입니다" 로 잡아준다.
